# CyberHub — Personal Cybersecurity + AI Learning Platform

## 1. Project Overview

**CyberHub** is a personal web application that I want to develop throughout my 1.5-year Cybersecurity + AI education at IT Step Academy.

The main purpose of CyberHub is to help me study, organize educational materials, understand difficult concepts, prepare for exams, document my learning, and track my progress.

I want to create an application that I will actively use throughout my education, rather than just build a project for the sake of programming.

CyberHub will be developed gradually. As I learn new programming concepts and technologies, I will introduce new functionality and improve existing components.

I'm planning to use **Claude** and **Codex** to help me build this project.

## 2. Technology Stack

My preferred technologies for this project are:

- **Programming language:** Python
- **Backend:** Django
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQL (SQLite initially, potentially PostgreSQL later)
- **AI:** Ollama (local LLMs)
    - Model `llama3.1:8b`
- **AI Framework:** LangChain (optional, when needed)
- **Containerization:** Docker
- **Version Control:** Git and GitHub

I prefer local AI solutions through Ollama whenever possible instead of relying on external cloud AI APIs.

The architecture and exact technology choices will be discussed and planned before implementation.

## 3. Main Components

**CyberHub** will initially contain five main components.
- AIM
- QEF
- NTT
- CLV
- PTM


### 1. AIM — AI Mentor

**Full name:** AI Mentor

A personal AI-powered learning assistant that helps me understand cybersecurity, programming, networking, Linux, and other subjects covered in my education.

Potential functionality:
- Ask questions about technical subjects.
- Receive beginner-friendly explanations.
- Upload educational PDFs and documents.
- Ask questions based on uploaded learning materials.
- Generate summaries.
- Explain technical commands and concepts.
- Maintain conversation history.
- Help me understand difficult topics.

The AI Mentor will primarily use Ollama for local AI functionality. LangChain and RAG may be introduced later.

### 2. QEF — Quiz as Exam Forge

**Full name:** Quiz Exam Forge

A quiz and examination preparation component designed to help me test my knowledge and prepare for school assessments.

Potential functionality:
- Create quizzes.
- Generate questions based on educational materials.
- Multiple-choice questions.
- True/false questions.
- Different difficulty levels.
- Track quiz results.
- Review incorrect answers.
- Identify topics that require additional studying.
- Monitor quiz performance.

### 3. NTT — Note Taking Tool

**Full name:** Note Taker

A note-taking component for organizing and storing everything I learn throughout my education.

It should support **Markdown** format only.

Potential functionality:
- Create and edit notes.
- Organize notes by subjects and categories.
- Add tags.
- Store technical explanations.
- Save code snippets and examples.
- Attach screenshots and documents.
- Search through notes.
- Edit and manage previously created notes.
- Potentially use AI to summarize or explain notes.

### 4. CLV — Command Library Vault

**Full name:** Command Library Vault

A searchable personal library for storing Linux commands, Python snippets, cybersecurity commands, and other useful technical references.

Potential functionality:
- Save commands.
- Organize commands into categories.
- Store command descriptions.
- Explain command parameters.
- Provide usage examples.
- Search for commands.
- Save frequently used commands.
- Add personal notes and explanations.

The goal is to create a personal technical reference that I can use during practical exercises and independent studying.

### 5. PTM — Progress Tracking Manager

**Full name:** Progress Tracking Manager

A component responsible for tracking and managing my educational progress throughout the 1.5-year program.

Potential functionality:
- Track completed lessons and topics.
- Set learning goals.
- Record study hours.
- Track subjects and learning progress.
- Identify topics that need revision.
- Monitor completed quizzes and practical exercises.
- Visualize learning progress.
- Maintain a history of my educational development.

## 4. Project Philosophy

CyberHub should be developed gradually throughout my education.

I do not expect to implement all five components immediately.

I want to start with a properly planned foundation and progressively introduce components and functionality as my knowledge improves.

The application should be:
- Modular and maintainable.
- Beginner-friendly to develop.
- Secure.
- Well-organized.
- Scalable enough to accommodate future functionality.
- Practical and genuinely useful for my education.

I also want to understand the code and technologies being used instead of simply receiving finished code.
